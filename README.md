# HEROIS-DE-PATAS

FIFI E SUA TURMA - Um jogo divertido de aventura na natureza com cachorros e gatos heróis!

## Como Jogar

- Use as setas para movimentar seu personagem.
- Pule para coletar ossos, moedas e corações.
- Derrote inimigos pulando sobre eles.
- Complete a fase coletando todos os itens e derrotando inimigos para abrir a porta.

## Personagens
Tutora jamais esquecida:Maria Estela

- Fifi 🐕: Líder corajosa
- Pretinha 🐈‍⬛: Ágil e esperta
- Totó 🐶: Brincalhão e forte
- Zarolho 😼: O gato vesgo perspicaz
